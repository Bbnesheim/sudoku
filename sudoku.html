How to Play

Rules

Fill every row, column, and 3×3 box with digits 1–9 with no repeats. Each puzzle has exactly one unique solution.

Controls

Hint — highlights a cell whose pencil marks contain the correct answer
Reveal Cell — fills a random empty cell with the correct number
Notes — toggle pencil mode to write candidate numbers in cells
Erase (toolbar) — clears a cell's value AND all pencil marks
Backspace (numpad) — in notes mode clears pencil marks only; in normal mode clears value

Keyboard Shortcuts

1–9 Enter number  ·  0 / Del Erase cell

↑↓←→ Navigate grid  ·  P Toggle notes mode

Ctrl+Z Undo  ·  Esc / Space Pause/resume
