# The Garden: Oz Configuration

This file guides Oz on how to work within this project.

## Branch Strategy

- **production** — active development and deployment branch. All work happens here until launch.
- **main** — stable release branch. Only merged to when ready for production launch.
- Feature branches are not used; work directly on `production`.
- Always push and commit changes to `production` unless explicitly told otherwise.

## Task Management

The main task reference for this project is **AGENT_SPEC.md** at the repo root. It contains:
- App identity and structure
- All phases of development (1–10)
- Scoring logic and game mechanics
- UI/UX specifications
- QA checklist before store submission
- Execution order for features

**When starting work:** Review the relevant phase in AGENT_SPEC.md to understand requirements.

## Project Structure

- **index.html** — Home page (hub) with game cards
- **sudoku.html** — Sudoku game
- **wordle.html** — Wordle game (coming soon)
- **assets/** — Icons, images, app assets
  - **assets/icons/sprite.svg** — SVG symbol sprite for all UI icons
- **docs/** — Documentation (if needed)
- **.claude.md** — This file (Oz configuration)
- **ARCHITECTURE.md** — Project structure and code organization
- **CONTRIBUTING.md** — Guidelines for making changes
- **README.md** — User-facing project information

## Key Technologies

- **Vanilla HTML/CSS/JS** — No build step, single-file architecture
- **PWA** — Service worker for offline support
- **localStorage** — Local statistics and user data
- **Capacitor** — (Phase 7+) Mobile app wrapper for Android/iOS
- **Supabase** — (Phase 6+) Backend for leaderboard sync

## Conventions

- Use `currentColor` for icon fills/strokes so they inherit button text color
- All modals pause the game timer when opened
- Dark mode preferences are persisted in localStorage
- Scores and statistics are stored in localStorage with Supabase sync ready
